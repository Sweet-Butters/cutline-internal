# Cutline v2 · 내부 발표 준비 QA 10문항

내부용. 2026-11-20. 근거: MEASUREMENT.md, video-ide/README.md, 사용자 브리프, facts.json 및 REPORT.md.

## 1. 사람 편집과 구별할 수 없다는 뜻인가요?

그것은 목표입니다. 이번에 관찰한 것은 단일 참조 사례에서 채널 규칙을 준 AI의 시간 겹침이 개선된 결과입니다. 채널다움과 자연스러움은 창작자 블라인드 비교와 실제 수정 시간으로 따로 검증해야 합니다.

## 2. 정답과 F1은 어떻게 만들었나요?

사람 편집본 23:18을 소리 대조로 원본 2:01:33의 위치에 정렬했습니다. 복원된 부분은 편집본의 93.55%입니다. 원본 시간축에서 AI가 남긴 구간과 사람 구간이 얼마나 겹치는지 precision과 recall의 조화평균으로 측정합니다. 순서·호흡·자막·화질·재미까지 평가하는 지표는 아닙니다. 미정렬 부분은 정답 근거로 취급하지 않습니다.

## 3. 세 번 평균이면 일반화가 입증됐나요?

아닙니다. 원본과 참조 편집본은 한 쌍이고, 각 조건의 에이전트 실행을 세 번 반복했습니다. 스타일 규칙도 이 사례를 관찰해 만든 것이므로 독립 영상의 일반화 결과가 아닙니다. 다음에는 스타일 도출용 영상과 평가용 영상을 분리하고 동일 길이 조건으로 평가하겠습니다. 통계적 유의성을 주장하지 않습니다.

## 4. 핵심 장면 24개 중 7개는 어떤 기준인가요?

사람이 15초 이상 남긴 24개 구간을 핵심 장면으로 정의했고, 해당 구간의 30% 이상을 AI가 남기면 포착으로 셌습니다. 대본만 준 조건은 2.7개, 스타일 규칙을 준 조건은 7개로 각각 세 번 평균입니다. 전체 재미 점수가 아닙니다.

## 5. 2~3분이면 완성 영상이 나오나요?

준비된 대본과 프로젝트에서 Claude Code 구독 에이전트가 편집을 수행한 시간입니다. 전사·프록시 준비, 최종 렌더, 사람이 보고 고치는 시간은 분리해야 합니다. 영상 전체 제작 시간의 절감률을 측정한 결과는 아닙니다.

## 6. 신호 도구를 넣으면 더 좋아진 것이 확인됐나요?

공연·함성처럼 사람이 살린 장면과 소리 신호가 겹친다는 발견을 설계에 반영했습니다. 신호 도구 제공은 구현 상태로 브리프에서 전달받았습니다. 신호와 에이전트의 조합이 더 좋은 편집을 안정적으로 만든다는 주장은 아직 목표입니다. 덱의 개선 수치는 대본만 준 조건과 스타일 규칙 조건의 비교입니다.

## 7. Descript나 MCP 도구와 무엇이 다른가요?

그 도구들도 대화형 편집, 타임라인 작업, 자동 QA를 제공합니다. Cutline은 사용자의 구독 에이전트가 편집한 변경을 로컬 작업 공간에서 재생·비교하고, 편집 사양과 채널 규칙을 검사한 뒤 사람이 버전으로 적용하는 흐름에 집중합니다. 채널별 메모리 축적과 다중 채널 운영은 유료 제품 목표입니다. 타사에 특정 기능이 전혀 없다고 주장하지 않습니다.

## 8. 추론 비용이 거의 0이면 이익도 거의 전부인가요?

고객이 본인 구독을 직접 인증하고 사용하므로 Cutline이 AI API 사용료를 대신 내지 않는 구조입니다. 사용자의 구독 비용과 한도는 남아 있습니다. 메모리 저장, 지원, 배포, 결제 수수료와 개발비는 별도입니다. 확정 마진을 주장하지 않습니다. 무료 앱 배포와 유료 서비스 출시 과정에서 서비스 조건도 확인해야 합니다.

## 9. 제안 가격과 시장 수요의 근거는 무엇인가요?

가격은 채널 메모리 월 12,000원, 편집자 월 39,000원(5개 채널 포함, VAT 포함)의 검증 목표입니다. 경쟁 가격은 2026-11-20 공식 사이트를 확인했으며 결제 주기·프로모션을 분리했습니다. 유료 고객·매출·지불 의향 실측이 아닙니다. RAPA 채널 수와 SOOP 사람 수는 합산하지 않습니다. 수입은 순소득이 아니며 외주비는 과거 가격의 조건부 산식입니다.

## 10. 지금 시연에서 볼 수 있는 것과 남은 것은 무엇인가요?

앱 README와 샘플 스크린샷에서 대화창, 변경·재생·비교, 검증표, 버전과 MP4 내보내기 흐름을 확인했습니다. 덱의 화면은 합성 샘플입니다. 실제 방송 실측은 별도 MEASUREMENT.md 근거입니다. 데모 MP4는 입력에 없으므로 1분 촬영 구성안을 만들었습니다. 실제 방송 촬영·공개 범위는 별도 준비가 필요합니다. 유머 타이밍·채널다움은 검증표만으로 통과 판정할 수 없습니다.
